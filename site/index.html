maps.sustenaut.eu

Maps of Estonia from open state data (Maa- ja Ruumiamet's ETAK, EHAK and the Building Register, and RMK's trails), built weekly, for any sustenaut.eu site.

Use it

<div id="map" style="height: 400px"></div>
<script type="module">
  import { createMap } from "https://maps.sustenaut.eu/lib/v1/map.js";
  const { map, maplibre } = await createMap(document.getElementById("map"), {
    center: { lat: 57.729, lng: 26.929 }, radiusKm: 25, zoom: 11,
  });
  new maplibre.Marker().setLngLat([26.929, 57.729]).addTo(map);
</script>
